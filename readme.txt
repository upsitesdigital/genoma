== Description ==

UpWork Framework é o tema base da UpSites para sites sob medida. Cada página é um módulo
(controller + seções em templates PHP com Tailwind CSS), renderizado no servidor com os dados
dos campos ACF; a interatividade (menu, abas, acordeões) usa a Interactivity API do WordPress,
sem jQuery. Posts, arquivos, busca e 404 seguem a hierarquia de templates do WordPress.

O tema é feito para ser editado direto (cada projeto é uma cópia do framework): não foi
pensado para uso com tema filho — views, seções e assets são lidos do tema pai.

== Installation ==

1. Gere o pacote com `npm run package` (dist/{tema}.zip, já com o build em assets/).
2. Em Aparência → Temas → Adicionar novo → Enviar tema, envie o zip e ative.
3. Instale e ative os plugins: Yoast SEO (o SEO do site é feito por ele), Contact Form 7
   (formulários) e, para enviar SVG, Safe SVG (marque só Administrador em "Upload roles").
